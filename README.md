# DemoBlaze Ecommerce Automation

Selenium WebDriver + TestNG + Maven + Extent Reports project for https://www.demoblaze.com

## Tech Stack
- **Language**: Java
- **Automation**: Selenium WebDriver 
- **Framework**: TestNG, Maven
- **Reporting**: Extent Reports
- **IDE**: Eclipse

## Test Cases Covered
1. User Login 
2. Add to Cart functionality  
3. Product Listing and Navigation
4. End to End Purchase Flow

## How to Run
1. Clone this repo
2. Import as Maven Project in Eclipse
3. Run `mvn test` or TestNG.xml

## Reports
Open `Reports.zip` to see Extent HTML Reports
